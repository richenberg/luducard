# Luducard

Luducard backs up and restores PC and emulator game saves, with a community hub for sharing save checkpoints and graphics presets.

## Language

**Save**:
The game's own progress files, in the location the game writes them.
_Avoid_: Backup (for this meaning)

**Backup**:
A copy of a game's saves kept by Luducard, from which they can be restored.
_Avoid_: Save, snapshot

**Backup folder**:
The single folder where Luducard keeps every backup, chosen by the user.
_Avoid_: Default location, save location, backup path
